## 🎨 Screenshot Best Practices

### 1. Timing
- Take screenshots during **peak usage** (when app looks best)
- Ensure **no loading states** or errors
- Show **real data**, not placeholders

### 2. Content
- Use **Arabic language** (primary market)
- Show **popular/trending** content
- Include **verified users** if possible
- Display **high engagement** numbers

### 3. Quality
- Use **highest resolution** device
- Ensure **no blur** or compression
- Check **colors are vibrant**
- Verify **text is readable**

### 4. Consistency
- Use **same account** across screenshots
- Maintain **same time of day** (for consistency)
- Keep **same theme** (dark mode)

---

## 🛠️ How to Take Screenshots

### Method 1: Device Screenshots
1. Open app on physical device or simulator
2. Navigate to desired screen
3. Press **Volume Up + Power** (iPhone)
4. Screenshots saved to Photos

### Method 2: Simulator Screenshots
1. Open Xcode Simulator
2. Navigate to desired screen
3. Press **Cmd + S** to save screenshot
4. Choose location to save

### Method 3: Expo Screenshots
1. Run `npx expo start`
2. Open on device
3. Use device screenshot function
4. Transfer to computer

## 📤 Upload to App Store Connect

### Steps
1. Log in to [App Store Connect](https://appstoreconnect.apple.com)
2. Select your app
3. Go to **App Store** tab
4. Scroll to **App Previews and Screenshots**
5. Click **+** to add screenshots
6. Drag and drop images
7. Arrange in desired order
8. Add captions (optional)
9. Save changes

### Captions (Optional)
- Keep under 170 characters
- Use Arabic for primary market
- Highlight key feature in each screenshot

**Examples:**
```
1. "شاهد المباريات الحية وتوقع النتائج"
2. "تفاصيل المباراة مع إحصائيات شاملة"
3. "شارك فيديوهاتك مع عشاق الكرة"
4. "اختبر معلوماتك في الكويز اليومي"
5. "بروفايل احترافي بطاقة فيفا"
```

## 🎯 Quick Capture Checklist

### Before Starting
1. ✅ Charge device to 100%
2. ✅ Set device to **Do Not Disturb**
3. ✅ Close all background apps
4. ✅ Set time to **9:41 AM** (Apple standard)
5. ✅ Enable **full signal** and **WiFi**
6. ✅ Set battery to **100%** (if possible)

### During Capture
1. ✅ Navigate to each screen
2. ✅ Wait for content to load fully
3. ✅ Take multiple shots of each screen
4. ✅ Review each screenshot immediately
5. ✅ Retake if needed

### After Capture
1. ✅ Transfer to computer
2. ✅ Rename files clearly
3. ✅ Check resolution and quality
4. ✅ Organize in folder
5. ✅ Upload to App Store Connect
