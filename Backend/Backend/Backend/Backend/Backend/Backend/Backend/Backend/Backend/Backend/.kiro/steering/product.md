# Product Overview

90Plus is a football (soccer) social media and engagement platform that combines real-time match data, video content sharing (reels), predictions, quizzes, and gamification features.

## Core Features

- Real-time football match tracking with live scores and predictions
- Short-form video content (reels) with social interactions (likes, comments, shares)
- Daily quiz system with multiple categories (legends, transfers, etc.)
- Match predictions with coin rewards
- User profiles with FIFA-style card customization
- Gamification: coins, XP, levels, achievements, daily spin wheel
- Social features: follow system, notifications, user rankings
- Multi-language support (8 languages: EN, AR, ES, FR, DE, IT, PT, TR)
- Content moderation with strikes and reporting system

## User Types

- Regular users (fans)
- Developers (special privileges)
- Admins (moderation and management)

## Platform

Mobile-first application built with React Native/Expo, targeting iOS and Android with web support.
