# ⚽ Football Profile Components

مجموعة مكونات احترافية لإدارة البروفايلات واللاعبين في تطبيق كرة القدم مع كروت شبيهة بالفيفا.

## 🚀 الميزات الرئيسية

### 🎴 كروت شبيهة بالفيفا
- كروت متدرجة الألوان (برونزي، فضي، ذهبي، ماسي)
- معلومات شاملة عن اللاعب
- نظام النقاط والمستويات
- شعارات الأندية العربية والعالمية
- انيميشن احترافية ومتطورة

### 👤 نظام البروفايلات المتقدم
- بروفايلات تجريبية متنوعة
- نظام التصنيف والمراكز
- إحصائيات مفصلة
- تفاعل مع المحتوى
- مشاركة البروفايلات

### 🔍 البحث المتقدم
- بحث ذكي في البروفايلات
- فلترة متعددة المستويات
- نتائج فورية مع انيميشن
- اقتراحات ذكية

## 📦 المكونات المتاحة

### FifaCard
```tsx
<FifaCard
  profile={profileData}
  onPress={handlePress}
  showActions={true}
/>
```

### ClubLogos
```tsx
<ClubLogo
  club={clubData}
  size={50}
  onPress={handlePress}
  showName={true}
/>
```

### ProfileSections
```tsx
<ProfileSections
  userId="user-id"
  activeTab="videos"
  onTabChange={handleTabChange}
/>
```

## 🎯 أنواع الكروت

### 🥉 الكارت البرونزي
- اللاعبين المبتدئين
- لون برونزي مميز
- معلومات أساسية

### 🥈 الكارت الفضي
- اللاعبين المتوسطين
- لون فضي أنيق
- إحصائيات متقدمة

### 🥇 الكارت الذهبي
- اللاعبين المحترفين
- لون ذهبي لامع
- ميزات خاصة

### 💎 الكارت الماسي
- اللاعبين المميزين
- لون ماسي فريد
- ميزات حصرية

## 🏟️ شعارات الأندية

### الأندية العربية
- **مصر**: الأهلي، الزمالك، الأهرام
- **السعودية**: الهلال، النصر، الاتحاد، الشباب
- **الإمارات**: العين، الوحدة
- **قطر**: السد، الريان
- **المغرب**: الوداد، الرجاء
- **الجزائر**: مولودية الجزائر
- **تونس**: الترجي

### الأندية العالمية
- **إسبانيا**: ريال مدريد، برشلونة، أتلتيكو مدريد
- **إنجلترا**: مانشستر سيتي، ليفربول، مانشستر يونايتد، أرسنال، تشيلسي
- **ألمانيا**: بايرن ميونخ، دورتموند
- **فرنسا**: باريس سان جيرمان، أولمبيك مارسيليا
- **إيطاليا**: يوفنتوس، إنتر ميلان، إيه سي ميلان
- **هولندا**: أياكس
- **البرتغال**: بنفيكا، بورتو
