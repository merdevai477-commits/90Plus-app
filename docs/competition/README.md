## جملة التعريف

**90Plus** منصة موبايل لعشاق كرة القدم تجمع النتيجة الحية، الفيديو القصير، التوقعات، المسابقات، ومساعدًا ذكيًا يجيب من بيانات المباريات الحقيقية — بالعربية والإنجليزية.

الموقع: [https://90plus.pro](https://90plus.pro)

## ما لا تدّعيه أمام اللجنة

- لا تذكر عدد المستخدمين أو حجم الإيراد إلا إذا كان عندك رقم رسمي.
- اللغات المنشورة اليوم: **العربية والإنجليزية**. العربية هي لغة أول فتح للتطبيق.
- المنصات الأساسية: **iOS و Android**. موقع `90plus.pro` صفحة تعريف وروابط مشاركة، والـ API يخدم التطبيق.
