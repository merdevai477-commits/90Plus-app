# 💰 نظام الكوينات الموحد

## نظرة عامة
نظام كوينات مركزي موحد يربط جميع صفحات التطبيق ببعضها.

## الرصيد الابتدائي
- **50 كوينة** لكل مستخدم جديد عند التسجيل

## طرق كسب الكوينات

### 1. التوقعات الصحيحة (صفحة المباريات)
- **+5 كوينات** لكل توقع صحيح
- يتم إضافة الكوينات تلقائياً عند انتهاء المباراة

### 2. الإجابات الصحيحة (صفحة الأسئلة)
- **+5 كوينات** لكل إجابة صحيحة
- يتم إضافة الكوينات فوراً

## استخدام الكوينات

### في صفحة الأسئلة:
- **10 كوينات**: استخدام Hint (حذف إجابتين خاطئتين)
- **20 كوينة**: تخطي السؤال

## التقنيات المستخدمة

### CoinsContext
```typescript
import { useCoins } from '@/contexts/CoinsContext';

const { coins, addCoins, subtractCoins } = useCoins();
```

### AsyncStorage
- المفتاح: `@user_coins`
- يتم حفظ الرصيد محلياً على الجهاز
- يتم تحميل الرصيد عند بدء التطبيق

## الملفات المعنية

1. **contexts/CoinsContext.tsx** - النظام المركزي للكوينات
2. **app/(tabs)/leagues.tsx** - عرض الكوينات في صفحة المباريات
3. **app/(tabs)/quiz.tsx** - استخدام الكوينات في الأسئلة
4. **services/predictionStorage.ts** - إضافة كوينات للتوقعات الصحيحة
