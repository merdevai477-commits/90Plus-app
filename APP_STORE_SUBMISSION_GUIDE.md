## 🔄 IF REJECTED

### Common Rejection Reasons:
1. **Copyright Issues**: Real names/logos used
   - **Fix**: Replace with generic names
   
2. **Age Gate Missing**: No age verification
   - **Fix**: Implement AgeGate component
   
3. **IAP Issues**: Coins purchasable without IAP
   - **Fix**: Add disclaimer or implement IAP
   
4. **Permissions**: Missing usage descriptions
   - **Fix**: Add to Info.plist
   
5. **Crashes**: App crashes during review
   - **Fix**: Test thoroughly, fix bugs
   
6. **Content**: Inappropriate content found
   - **Fix**: Improve moderation
